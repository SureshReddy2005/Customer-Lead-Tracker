# Customer Lead Tracker
A lightweight Customer Relationship Management (CRM) utility built to demonstrate core full-stack principles. This project simulates the foundational layer of a CRM platform (like Salesforce) by allowing users to capture, store, and display customer lead data.

## Tech Stack
* **Frontend:** HTML5, CSS3 (Responsive UI design)
* **Backend:** Java (Core Java, JDBC)
* **Database:** MySQL / SQL

## Features
* **Lead Capture:** HTML/CSS forms to securely capture customer details.
* **Database Persistence:** SQL schema enforcing data integrity (unique emails, auto-incrementing IDs).
* **Java Integration:** JDBC implementation demonstrating database connectivity and Prepared Statements to prevent SQL injection.

## Project Structure
* `/frontend` - Contains the UI layout and styling.
* `/backend` - Contains the Java logic for database connectivity and CRUD operations.
* `/database` - Contains the SQL scripts for table creation and mock data insertion.
